# kernel/arch/aarch64

AArch64 target (Phase 13): the second implementation of `kernel/include/arch/*.h`, sibling of `kernel/arch/x86_64/`. Runs on QEMU's `virt` machine with EDK2 firmware (`make ARCH=aarch64 test`). Entry from the loader at EL1 with the MMU on (`entry.S`, `start.c`), the 16-slot exception vector table and trap frame (`vectors.S`, `trap.c`), GICv2 plus GICv2m MSI behind `arch/irqc.h` with GSI = INTID (`gic.c`), the generic timer with absolute compares (`timer.c`), a 4-level stage-1 MMU with TTBR1 for the kernel and TTBR0 per user context (`mmu.c`), TPIDR_EL1 per-CPU (`percpu.c`), context switch and EL0 entry (`switch.S`, `context.c`, `user.c`), the user copy primitive with exception fixups (`uaccess.S`), PSCI secondary bring-up through an identity-mapped trampoline (`smp.c`, `trampoline.S`), PL011 console and MMIO fw_cfg (`pl011.c`, `fwcfg.c`), `R_AARCH64` module relocations (`modreloc.c`), the x29 backtrace, semihosting exit, and a stub `arch/hv.h` backend. Private headers in `include/aarch64/`. Documented in `docs/kernel/arch/aarch64/`.
