# scripts/frame-baseline.txt -- kernel and module functions exempt from the
# 2048-byte stack-frame guard (-Wframe-larger-than=2048, build/toolchain.mk;
# FRAME_EXEMPT_BEGIN/END in kernel/include/kernel/compiler.h). Kernel stacks
# are 16 KiB (THREAD_STACK_SIZE, kernel/include/kernel/thread.h).
#
# The guard was added with a baseline of 32 functions (roadmap M3,
# 2026-10-10). Milestone M6 (2026-10-12) rewrote all 32 below the limit:
# path buffers and the fsck report moved to the heap, the AArch64 Linux
# signal frame is written to user memory in pieces, the NVMe PRP list is
# written straight into the command slot, and self-test buffers became
# static (docs/audit/2026-10-12-m6-release-report.md, "Stack frames").
# No function is exempt.
#
# An exemption is one line, every field required, with its evidence:
#   <source file> <function> <largest frame, bytes, any of x86-64/AArch64
#   debug/release> <deepest measured stack use, bytes> <reason ...>
# and the function wrapped in FRAME_EXEMPT_BEGIN/END in its source.
# scripts/check-frame-baseline.py fails the kernel link when the wrapped
# set and this list differ, or a line has no reason.
